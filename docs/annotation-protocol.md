# Provisional manual annotation protocol

This is a proposal for advisor review, not a validated Niles-specific hydrological definition.

Target: complete elevated-flow response episodes. A compound episode can contain multiple pulses without clear recovery between them. Do not call every such episode one meteorological storm. Resolve this target definition before pooling labels across sites.

Start: choose the observation before a sustained response rise, considering the preceding trend and fluctuations. End: choose a justified transition toward background recession, or an interruption by a subsequent response; record the endpoint basis and uncertainty. The horizontal start-flow line is a reference, not an endpoint rule. No fixed duration or return-to-original-flow requirement is imposed.

For each event record single/compound structure, start/end confidence, likely cause, completeness, notes, and optional earliest/chosen/latest end. Mark secondary peaks manually. Review sharp anomalies against source quality flags. Choose rainfall intervals separately; rainfall after the flow endpoint should not be attributed automatically. No rain is not proof of snowmelt.

Reviewed non-event intervals must be explicitly marked; unlabeled periods are not negative examples. Review a diverse pilot independently with a second annotator, resolve disagreements, and version the labeling policy. Boundary agreement measures reproducibility, not physical ground truth.

References:
- [Tarasova et al. (2018)](https://doi.org/10.1029/2018WR022587): baseflow separation, event identification, rainfall attribution, and multiple-peak refinement; daily-data study with catchment-dependent assumptions.
- [Ashe et al. (2026)](https://doi.org/10.1002/rra.70159): sub-hourly event extraction and dynamic thresholds.
